# RAS215_Slides

HTML lecture slides for RAS 215, written by the TA. They follow R. C. Hibbeler, *Statics and Mechanics of Materials*, 6th ed. Each slide is generated by a short Python script, and the figures and animations are SVG computed from the textbook equations.

| Lecture | Deck |
|---|---|
| Ch. 15: Design of Beams and Shafts | [`ch15/slides/RAS215_Ch15_Design_of_Beams_and_Shafts.html`](ch15/slides/RAS215_Ch15_Design_of_Beams_and_Shafts.html) |

## Viewing a deck

Download the deck `.html` file and open it in Chrome. It is a single file with no internet needed. (GitHub only shows the source, not the slides.)

| Key | Action |
|---|---|
| → / Space / PageDown / click | next step or slide |
| ← / PageUp | back |
| Home / End | first / last slide |
| F | full screen |
| R | restart the current slide |
| `#N` at the end of the URL | open slide N |

## Building

Python 3 only, standard library, no packages. From `ch15/scripts/`:

```
python3 05_make_slide3_section.py   # rebuild one slide → ../slides/separate/
python3 90_make_deck.py             # join all slides into the deck
```

Add `?t=SECONDS` to a single slide's URL to freeze its animation at that time, which is useful for screenshots.

## Layout

```
CLAUDE.md          how the slides are made: source rules, design, style, build (start here)
docs/              style guides used (presentation guideline, slide style, matplotlib style)
assets/            logo, background photos, maths font (STIX Two Math, OFL)
ch15/
  plan.md          slide plan for the lecture
  log.md           dated change log
  scripts/
    01_slide_lib.py      shared page frame, colours, helpers
    NN_make_*.py         one script per slide
    90_make_deck.py      builds the deck; DECK lists the slide order
  slides/
    separate/            one HTML file per slide
    RAS215_Ch15_*.html   the full deck
```

## Making a new lecture

1. Copy `ch15/` to `chNN/` and remove its slide scripts, keeping `01_slide_lib.py` and `90_make_deck.py`.
2. Add a "Case: Ch. NN" section to `CLAUDE.md` with the source pages.
3. Write one script per slide, list the slides in `DECK`, and build.

The textbook page photos are not included (copyright). Every slide cites its book page.
